# Changelog

## v1.2.0

- Added a searchable location field to hardware records.
- Added an optional operating system field to tickets, with suggestions, search, and export support.

## v1.1.0

- Added a searchable hardware catalog with device type, make, model, power cable or adapter, and ink or toner.
- Added local manual attachments and included hardware and manuals in JSON backups.

## v1.0.0

- Added the offline Windows ticket browser and editor, requester autocomplete, search, and priority filters.
- Added versioned SQLite storage, permanent ticket numbering, and progress history.
- Added CSV and Excel exports, monthly summaries, JSON backup and restore, and a single-executable Windows build script.
